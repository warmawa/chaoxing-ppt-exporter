# 学习通课件导出器 · Chaoxing PPT Exporter

> 把超星学习通课程章节里**只能在线翻页**的 PPT 课件，导出成 PDF 或直接下载原始文件。

学习通把上传的 PPT 转成了图片序列，只给你一个能翻页的浏览器窗口——没有下载按钮，
右键也存不下一整套。这个工具就是为解决这件事写的：它能认出当前页面里的课件，
帮你把整套内容拿下来，方便离线复习、做笔记，或者喂给 AI 做总结。

提供**浏览器扩展**和**油猴脚本**两种形式，功能一致，按习惯选一个即可。

---

## 功能特性

| 能力 | 说明 |
| --- | --- |
| **三种策略自动择优选** | 优先拿服务器上的原始文件直链（无损），退而求其次拿转码 PDF，最后才逐页下载图片自己合成 |
| **零依赖 PDF 生成** | 不引入 jsPDF 之类的库，JPEG 直接以 `DCTDecode` 原样嵌进 PDF，体积几乎等于原图之和，画质无损 |
| **多 iframe 穿透** | 学习通的课件藏在三四层嵌套 iframe 里，脚本注入所有 frame 后由后台统一去重，只弹一个面板 |
| **图片请求监听** | 在页面脚本运行前劫持 `img.src` / `fetch` / `XHR`，只要图片加载过就能抓到，不依赖固定的 DOM 结构 |
| **自动滚动加载** | 导出前自动把课件滚到底，触发懒加载，避免只抓到前几页 |
| **并发下载 + 自动重试** | 默认 6 并发、失败重试 3 次，可调；个别页面失败不会让整个任务挂掉 |
| **常驻悬浮面板** | 打开学习通任意页面就出现，不等探测结果；Shadow DOM 隔离样式，可拖动、可最小化成小球，带进度条和诊断信息 |

## 安装

### 方式一：浏览器扩展（推荐）

支持 Chrome / Edge 等 Chromium 内核浏览器（Chrome 109+）。

```bash
git clone https://github.com/warmawa/chaoxing-ppt-exporter.git
```

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）
2. 打开**开发者模式**开关，两个浏览器的位置不一样：

   | 浏览器 | 开发者模式开关位置 | 按钮名称 |
   |---|---|---|
   | Chrome | 页面**右上角** | 加载已解压的扩展程序 |
   | Edge | 页面**左下角** | 加载解压缩的扩展 |

3. 点上面的按钮，选择仓库里的 `extension/` 目录
   - ⚠️ 要选到**直接包含 `manifest.json` 的那一层**（即 `extension/` 本身），选到它的上一层会报 `Manifest file is missing or unreadable`
4. 装好后建议把图标固定到工具栏

> 想打包成 `.crx` 分发的话，用 Chrome 的"打包扩展程序"功能即可。

### 方式二：油猴脚本

适合不想装扩展、或想在 Firefox 上用的场景。

1. 先装一个用户脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) / Violentmonkey
2. 打开 `userscript/chaoxing-ppt-exporter.user.js`，粘贴到管理器里新建脚本，保存
   （或者把文件拖进浏览器窗口）

> 脚本必须跑在**所有 frame** 里：课件 iframe（`ananas.chaoxing.com` / `pan-yz.chaoxing.com`）
> 与章节页跨域，只在顶层跑的话看不见课件内部。
> Tampermonkey 默认就是全 frame 运行，**别在设置里勾"只在本页运行"**，
> 也**不要**给这个脚本加 `@noframes`。

## 使用方法

1. 登录学习通网页版，随便打开一个页面（课程列表、章节页都行）
2. 页面**最顶端**会浮出一个蓝色操作窗（**不用等课件加载，装了就在**）
3. 打开章节里的 PPT 课件，面板上会自动出现课件名、页数和操作按钮

面板固定在浏览器窗口顶部、水平居中，跟着窗口走而不是跟着课件走——课件再长也不用翻到底去找它。
（探测发生在课件所在的 iframe 里，但面板特意挂到了最外层窗口，就是因为课件 iframe 常被撑成
几千像素高，按钮放里面会沉到底部。）

浮窗有两种形态：

| 形态 | 怎么进入 | 能看到什么 |
|---|---|---|
| 浮窗（默认） | 打开任意学习通页面就出现 | 课件信息 + 操作按钮；**没检测到课件时显示诊断信息和「重新检测」** |
| 小球 | 点标题栏的 `–` | 缩成 46px 圆球，不挡视线；**球面上仍显示进度百分比** |

浮窗和小球都能**拖动**，各记各的位置；点小球展开回浮窗。

没检测到课件时，浮窗长这样：

```
插件已就绪，正在等课件加载
打开章节里的 PPT 课件，或往下翻几页触发加载，然后点重新检测。
[重新检测]
[诊断] 已监听 4 个框架 · 捕获图片 12 张 · 1 个框架有 fileinfo
```

那行 `[诊断]` 是排查用的：如果点了几次「重新检测」还是 0 张图片，把这行连同 F12 控制台里
`[CX]` 开头的日志一起提个 issue，基本能定位到卡在哪一步。

点 **提取并导出 PDF** 之后，浮窗里才展开**进度条**（没点之前不占位）：

- 蓝条 + `12/80 · 15%` — 正在下载图片，比例精确
- 蓝条左右滑动、不显示百分比 — 正在滚动加载页面或合成 PDF，这一步算不出确切比例
- 绿条 — 完成；红条 — 有部分页面失败

检测到课件后，浮窗上会显示课件名、页数和探测方式，然后：

- **下载原文件** — 服务器上有原始 PPT/PDF 时出现，拿到的是老师上传的原件（无损）
- **提取并导出 PDF** — 把课件逐页抓下来合成一个 PDF
- **复制直链** — 把推导出的直链复制走，方便自己用下载工具或脚本处理

### 面板一直停在「等待课件」？

按可能性排序，挨个试：

1. **手动往下翻几页课件** —— 图片是懒加载的，一页都没加载时脚本无从识别
2. 点面板上的**重新检测**
3. 等 5~10 秒 —— 脚本会在 1s / 2.5s / 5s / 9s 各探测一次，之后每 6 秒巡检
4. 打开控制台（F12）看有没有 `[CX]` 开头的日志
5. 刷新页面重来一次

### 点扩展图标能做什么

调整导出参数，改动即时保存：

- **图片质量**（60%~100%）—— 只影响"图片合成"方式，90% 以上肉眼看不出差别
- **并发下载数**（1~12）—— 调太高容易被限流，反而出现 403
- **单页最大宽度** —— 超宽图会按比例缩放，页数多的时候调低能显著减小体积
- **导出前自动滚动** —— 关掉的话可能只抓到已经翻过的几页

## 工作原理

学习通的课件链路上有好几层，工具做的事就是**逐层剥到最里面拿到真实资源**：

```
studentstudy 章节页
└── knowledge/cards
    └── ananas/modules/pdf/index.html      ← 课件预览器
        └── pan-yz.chaoxing.com/screen/v2/file_xxx   ← 云盘预览页
            ├── window.fileinfo.download  → 原始文件直链      【策略 A】
            ├── .../doc/<oid>/pdf/<oid>.pdf → 转码后的 PDF     【策略 B】
            └── .../doc/../<oid>/thumb/N.png → 逐页图片        【策略 C】
```

- **策略 A / B** 拿到直链后，直接让浏览器去下载——这样会带上你当前的登录态和
  Referer，比在扩展里伪造请求头可靠得多。
- **策略 C** 是兜底：把所有页面图片并发抓下来，`canvas` 转成 JPEG，
  再用自己写的 `PdfWriter` 拼成 PDF。超星返回的原图常常是 PNG，
  直接嵌进 PDF 会因为透明通道显示成黑块，所以统一铺一层白底再转 JPEG。

关于 PDF 生成器，有个容易被忽略的坑值得一提：PDF 的 `xref` 表记录的是
**每个对象在文件里的字节偏移**，算错一个字节，严格的阅读器就会拒绝打开文件
（浏览器通常很宽容，所以本地测试根本发现不了）。`test/verify-pdf.py` 就是
专门用来逐条核对这件事的。

更细的实现笔记见 [`docs/原理.md`](docs/原理.md)。

## 开发与测试

没有构建步骤，改完直接重新加载扩展即可。

```bash
# 探测器单元测试（URL 解析、序列聚类等纯逻辑，24 项）
node test/detector.test.cjs

# 面板契约 + 常驻设计要求（48 项）—— 这类"跨文件约定"漏了只会静默失效
node test/panel.test.cjs

# 消息通道一致性（24 项）—— 每个 cx:* 消息都必须有收发两端
node test/messaging.test.cjs

# 合成一个测试 PDF，产出在 test/output/sample.pdf
node test/build-sample-pdf.cjs

# 校验 PDF 结构：xref 偏移、对象引用、图片流完整性
python test/verify-pdf.py

# 重新生成图标（纯标准库，无 Pillow 依赖）
python tools/make_icons.py
```

测试素材放在 `test/fixtures/`，放几张 JPEG 进去即可。


## 常见问题

**Q：导出的 PDF 比原 PPT 大很多？**
图片型 PPT 本质就是几十张高清图，体积本来就大。把弹窗里的"单页最大宽度"调到
1600~2000，或把质量降到 80%，一般能砍掉一半以上。

**Q：卡在"正在下载图片"，然后部分页面失败？**
多半是被限流了。把并发数降到 2~3，或者隔几分钟重试。失败页面在结束时会有提示。

**Q：明明有课件，面板却不出现？**
先往下翻两页。如果还是没有，F12 看控制台里 `[CX]` 的日志，
以及 `window.fileinfo`、页面里 `img` 的 URL 形态，提 issue 时附上这些信息最容易定位。

**Q：能批量下载整门课吗？**
当前版本只处理你正在看的这一个课件。批量遍历整门课涉及更多页面结构，
在 TODO 列表里，欢迎 PR。

**Q：下载后的文件打不开 / 是坏文件？**
大概率是直链推导错了。点"复制直链"手动验证一下，欢迎带上日志提 issue。

## 已知限制

- 只在 Chromium 内核 + `chrome.*` API 下验证过，Firefox 需要改 `browser.*` 兼容层
- 超星前端改版频繁，探测策略可能需要跟着更新
- 面板会出现在所有 `*.chaoxing.com` 页面上（这是"常驻"的代价）；不想看时点 `–` 缩成小球或拖到角上
